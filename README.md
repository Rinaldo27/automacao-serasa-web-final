# automacao-serasa-web-final

Este projeto contém casos de testes end-to-end automatizados para aplicações web, utilizando o Cypress como framework principal. Os testes cobrem diversos fluxos de funcionalidades e garantem que o comportamento da aplicação esteja conforme o esperado. O objetivo é automatizar a validação de processos críticos e facilitar a manutenção contínua do sistema.

## 🛠️ Pré-requisitos
- Ter o NodeJS instalado
- Ter um editor de texto instalado
- Ter o git instalado
