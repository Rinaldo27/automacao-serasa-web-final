# automacao-serasa-web-final

Este projeto contém casos de testes end-to-end automatizados para aplicações web, utilizando o Cypress como framework principal. Os testes cobrem fluxos de gatilhos, funcionalidades e garantem que o comportamento da aplicação esteja conforme o esperado. O objetivo é automatizar a validação de processos críticos e facilitar a manutenção contínua do sistema.

## 🛠️ Pré-requisitos
- Ter o NodeJS instalado
- Ter um editor de texto instalado
- Ter o git instalado

## 📁 Estrutura do Projeto
- Diretórios e arquivos organizados conforme padrão Cypress
- Testes localizados em `cypress/e2e`
- Estrutura page objects aplicada e em construção 


## 📦 Instalação
Clone o repositório:

- git clone https://github.com/Rinaldo27/automacao-serasa-web-final.git
- cd automacao-serasa-web-final
- npm install

💡 Certifique-se de ter instalado as dependências com `npm install` antes de rodar os testes.

## Como executar:
- Abrir o Cypress com interface gráfica: `npm run cy:open`
- Executar os testes em modo headless (terminal): `npm run cy:run`
- Executar testes com configuração personalizada (split=true): `npm run test`
